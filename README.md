# Evacuate

Evacuate is a survival-horror game developed in Unity as a 4-person team project.

The player awakens alone in an abandoned science facility overrun with zombies. As they explore the facility, they must manage a limited inventory, solve puzzles, navigate new areas, and fight infected enemies while uncovering clues about what happened and searching for a way to escape.

## Technologies

- Unity
- C#
- Unity Version Control / Unity DevOps

## Repository

This repository contains selected source code from Evacuate, focusing on the systems and gameplay programming I contributed to.

The complete Unity project is maintained separately through Unity DevOps. Due to the size of the project and its collection of game assets, the full project is not included in this repository.
